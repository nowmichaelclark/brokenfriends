# Audio and music

## In charge of

All sound: Driftloom's generated music, each friend's theme, music
that follows the game's state, and sound effects.

## Not in charge of

- The Driftloom core itself (its own repo).
- The game states it reacts to: it only listens to other systems.

## Seed notes (from Mikey's first ideas, unconfirmed)

- Driftloom's Rust core in the game, later.
- Each friend has its own randomly generated theme song.
- Other music generated by time of day and what's happening.
- Claude's suggestions: a friend's theme can be a stored Driftloom
  song code, since a code always renders the same song; Driftloom's
  charter already plans a small API and C header for game engines, and
  "music for games" is on its roadmap; this game could be one of the
  charter's "three real games".

- Mikey (2026-10-24): Broken Friends is the most important of
  Driftloom's "three real games" (decision 0016).

- Spike 2 (2026-10-24): the core runs in the game, natively and in the
  browser, bit-identical to Driftloom; `game/autoload/music.gd` plays
  Driftloom's golden loops. Writing new music waits on Driftloom's
  phase 2 (its generator moving to Rust).

- Mikey (2026-10-24): "I hope eventually that Driftloom will be used to
  its full potential: music can be randomly generated, change depending
  upon events and time of day, what friend we're working on, a
  friend's mood, etc. There are many variables we could tie to the
  generation of loops." Needs Driftloom's phase 2 (its songwriting part
  moving into the Rust core), then its promise 11 (asking for music).
- Before that, the game must run smoothly on weak phones (Moto G Power
  2022 and weaker), or live music would make it worse.

- Every friend's voice must sound unique, across thousands, ideally
  10,000 or more, so voices need the same weighted generation as looks
  (recording 2, 2026-10-24).

## First questions

- Which game states map to which music settings?
- When two friends are on screen, whose theme plays?
- Which spike proves the core runs in a Godot build, browser included?
