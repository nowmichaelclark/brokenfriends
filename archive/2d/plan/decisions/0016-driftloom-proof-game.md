# 0016: Broken Friends is Driftloom's most important proof game

## Decision

Broken Friends is one of the "three real games" in Driftloom's core
charter, and the most important of them.

## Context

Q-009 asked whether the game should be one of the games that prove
Driftloom's core can live inside any game.

## Why

Mikey: "Yes, in fact it should be considered the most important, it's
the only one that really matters to me."

## Alternatives rejected

- **Driftloom later, as an extra:** the Driftloom lesson is that
  architecture found late costs a port.

## Consequences

- The `audio-music` system is planned in Phase 2 with everything else,
  even though it is built later.
- Running Driftloom's core inside a Godot build, browser included, is
  an early spike [unverified, V-008].
- Driftloom's own charter (`docs/CORE.md`, promise 10) should name
  Broken Friends; that's a change in the Driftloom repo.
