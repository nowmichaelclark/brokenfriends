# 0022: They are called friends, not creatures

## Decision

The game's word for the beings the player cares for is **friend**. The
docs stop saying "creature".

## Context

Mikey kept saying "bear" and wasn't sure the beings had a name. Asked
what the game should call them: "let's stop calling them creatures and
start calling them friends. Friends is a good thing to call them."

## Why

- It matches the title, Broken Friends, and the player's role as their
  doctor and friend (0009).
- "Creature" leans monster-movie; "friend" carries the warmth.

## Alternatives rejected

- **Creature:** cold, and not what the game calls them.

## Consequences

- `glossary.md` defines **Friend**; the living docs were renamed, and
  the `creature-body` system is now `friend-body`.
- Accepted decisions, the inbox and logs keep their original words.
- The sketch's code still says "creature" (0021: it may be redone).
