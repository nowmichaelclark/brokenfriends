# Time and saving

## In charge of

The game's clock, working out what happened while the app was closed,
and saving and loading everything.

## Not in charge of

- What time does to a friend: each system's own rules, applied when
  this system says time has passed.
- Where saves are stored on each platform: `platforms-tech`.

## Seed notes (from the first chat, unconfirmed)

- Claude's suggestion: don't run the game while it's closed; save a
  timestamp and work out what happened when it reopens.
- Driftloom's music may change with the time of day.

## First questions

- Real-world time, game time, or both?
- What stops players from cheating by changing the phone's clock, and
  does it matter?
- Cloud saves across phone and browser?
