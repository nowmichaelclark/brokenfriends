# Drafter session: notes into docs

**Tier:** F. **With:** Mikey, briefly.

## Purpose

Turn Mikey's decisions, notes and Brain-session output into clean docs
that follow the templates and the rubric. You organize and write; you
don't add design.

## Pack with

The target doc(s), the matching template from `kit/templates/`, the
notes or log to work from, related system docs, `kit/RUBRIC.md`.

## How to run it

1. Read the template and the rubric step the doc is aiming for.
2. Fill every section from the source material. Where the source says
   nothing, write "none yet", or put a question in
   `open-questions.md`. **Never invent design to fill a gap.**
3. Mark anything you inferred rather than read as
   `(inferred: please confirm)` so Mikey can check it.
4. Check terms against `glossary.md` and add any new ones.
5. Check "Talks to" against the other system docs you were given.
   Mismatches go in **Weak spots**.
6. Grade the result against the rubric step: list each box as met or
   not met.
7. Set the status to what the rubric allows (`draft` or `review`).
8. Return the files, the log note and **Weak spots**.
