# 0036: Making a friend from scratch

## Decision

A tool for making a friend from scratch is built, first for developers
(testing). Later it may become a late-game unlock: machines that make
skin, limbs and the rest, the brain last.

## Context

Q-013. Mikey: "I think even like as a dev tool, that would actually
make sense to be able to make creatures from scratch... maybe that's
the thing players unlock at the very, very end of the game."

## Why

- Generated friends (0037) need a tool to test them anyway.

## Alternatives rejected

- **Leave it as a door only:** the tool is useful from the start.

## Consequences

- Resolves Q-013. Whether players get it waits for later.
