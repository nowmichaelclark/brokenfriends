# 0039: Single player first, playable offline

## Decision

The game is single player and fully playable offline. Sharing friends
by a code is wanted. Online play is left room for, not planned.

## Context

Asked about multiplayer, Mikey: "we might do something similar to
Driftloom where you can share your creatures via like a code... let's
say we're single player focused first, and then online can be something
we save room for", like the old Pokemon games.

## Why

- No servers to run, nothing to break when offline.

## Alternatives rejected

- **Online from the start:** cost and complexity before the game is
  fun.

## Consequences

- A friend must be describable as a short code (the generator's
  numbers, 0037). `time-save` keeps everything on the device.
