# 0024: No corporate hooks

## Decision

No daily-login streaks, no energy timers that make the player wait, and
no notifications that nag the player to come back.

## Context

Asked which tempting features the game would refuse on purpose. Mikey:
"This is a game without that corporate style of thinking. Again, the
focus is fun and enjoyable." Earlier in recording 2: "we're not trying
to make the game like super, super, super addictive. It's more just
like, oh, it's nice to check in on your friends."

## Why

- These features exist to raise engagement numbers, not fun.
- Pillar 4 (nothing holds the player) and 0010 (nothing gated) already
  point this way; this names the usual offenders.

## Alternatives rejected

- **Gentle versions (a skippable streak, optional reminders):** still
  the same thinking.

## Consequences

- A non-goal in `00-vision/non-goals.md`.
- A notification may still say something the player asked to know
  (a friend is back from a quest) only if a later decision allows it.
