# Prototypes

One file per prototype or spike, from `kit/templates/prototype.md`:
`NN-short-name.md`. The build itself lives in the game repo once code
starts; this file holds the question, how Mikey judged it, the result,
and which docs changed.

A **prototype** answers a design question by playing ("is tearing fun?").
A **spike** answers a technical one ("does the Driftloom core run in a
Godot web build?"). Both use the same template.
